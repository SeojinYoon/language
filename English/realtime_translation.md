
#  한국말을 영문으로 옮길때 접속사를 빼먹는 경우가 많음

한국어와 영어의 구조적 차이 때문에 매우 자연스럽게 발생하는 현상.

한국어는 명사 뒤에 조사를 붙이거나 문맥으로 관계를 압축하는 반면, 영어는 두 요소 간의 논리적 결합 장치(접속사, 관계사, 전치사)를 문법적으로 반드시 겉으로 드러내야 한다.

- 한국어 화자가 접속사·관계사를 자주 빼먹는 3가지 패턴
    - 수식절 뒤의 명사 ('~하는 경우', '~하는 방법')
        * 한국어는 '라플라스 변환이 잘 작동하는(수식절) + 경우(명사)'처럼 그냥 이어붙임, 반면 영어는 명사 뒤에서 꾸며줄 때 반드시 관계부사/전치사라는 다리가 필요
            > 어색한 표현: The case Laplace transform works well  
            > 자연스러운 표현: The case where the Laplace transform works well
    - 목적·결과를 나타낼 때 ('~하도록', '~하기 위해서')
        * 한국어는 '-하도록 설정하다'처럼 동사 어미로 처리하지만, 영어는 절이 올 때 so that이나 in order that을 생략하면 문장이 두 개로 쪼개짐
            > 어색한 표현: Adjust the parameters, the model converges fast  
            > 자연스러운 표현: Adjust the parameters so that the model converges quickly
    - 조건·가정 및 인과관계 ('~하면', '~해서')
        * 구어체 한국어는 접속사 없이 쉼표나 어미로 연결하는 경우가 흔함
            > 어색한 표현: The dataset is noisy, we applied a filter  
            > 자연스러운 표현: Since the dataset is noisy, we applied a filter

# Real time thinking

- 결론(주어 + 핵심 동사)부터 먼저 뱉기
    * 한국어는 끝까지 들어봐야 하는 언어(주어 + 부가설명 + 목적어 + 동사)이지만, 영어는 누가 무엇을 한다/이다를 0.5초 안에 먼저 던지는 구조
        - 한국식 사고
            > "라플라스 변환이 잘 작동하는 경우들을 정리해 보면..."
        - 실시간 영어 사고: 결론부터 선언 후 뒤에 설명 붙이기
            > 뼈대 먼저 던지기: "Here are the cases..."  
            > 뒤에 다리 놓기: "...where the Laplace transform works well."

- 긴 문장을 쪼개고 '만능 연결 징검다리' 쓰기
    * 접속사를 완벽하게 구사해 한 문장으로 끝내려 하지 말고, 짧은 문장 2개로 나누거나 3가지 만능 연결 장치로 처리
        - 관계사 생략이 헷갈릴 땐 명사 뒤에 which / where / that을 일단 습관적으로 붙이기
        - 접속사 대신 전치사구로 우회하기
            * 절을 만들어 접속사를 고민하는 대신 for, to, with로 단순화
            > "I need to change settings so that the model converges faster." (접속사 신경 써야 함)  
            > $\rightarrow$ "I need to change settings to improve convergence." (to부정사/전치사로 해결)
- 문맥 단어' 대신 '기본 동사(Core Verbs)'로 생각하기
    * 머릿속 한국어의 고급 어휘를 영어 사전식 고급 단어로 바꾸려다 멈칫하게 됨. 회화와 실시간 작문에서는 8개의 기본 동사로 대부분의 개념을 처리할 수 있다
        - make, get, have, take, give, keep, work, use
